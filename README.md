# ReactionCreator Website

Production marketing and support website for ReactionCreator, the mobile reaction video editor.

## Pages

- `index.html`
- `features.html`
- `pricing.html`
- `privacy.html`
- `terms.html`
- `support.html`

## Assets

Production images, app icons, screenshots, and Google Play artwork live in `assets/img`.

## Local Preview

This site is static HTML, CSS, and JavaScript.

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.
